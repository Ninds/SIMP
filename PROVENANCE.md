# Provenance and editorial status

This repository combines locally recoverable generated artifacts with carefully reconstructed companion editions. The labels below are deliberate.

## Recovered artifacts

These items were present locally as complete LaTeX and PDF files and were copied into the repository with neutral filenames:

- `vectors-operators-and-function-spaces`
- `polar-coordinate-vectors`
- `spherical-laplacian`
- `random-walk-to-heat-equation`

Their mathematical content and diagrams were preserved. Markdown editions were created for repository browsing.

`schrodinger-equation-worked-models` was also recovered locally, but in a different form: its editable source was a complete illustrated HTML publication with an accompanying PDF, not LaTeX. The repository edition removes institution-specific identifiers, adds an explicit index of thirteen demonstrations, updates navigation and metadata, and supplies a Markdown reading edition. The HTML remains the editable source; no unavailable LaTeX original is claimed.

## Reconstructed editions

The following earlier files were referred to in chat history but their original sandbox files were not available in the local workspace:

- action/calculus-of-variations tutorial
- Lagrangian-mechanics tutorial
- Hamiltonian-mechanics tutorial
- illustrated Euler-Lagrange workbook

The repository versions are new, self-contained reconstructions based on the recoverable discussion, stated learning goals, and a fresh mathematical check. They are not represented as byte-for-byte copies of unavailable originals.

## Derived companion

`schrodinger-operator-bridge` is a focused companion derived from themes already developed in the recovered vectors-and-operators text. It was written as a shorter route through the relevant material rather than extracted verbatim.

## Integral theorems

The integral-theorems document is a new, institution-neutral tutorial created to cover topics mentioned in the recent study-document set. It is not a copy of a third-party course handout.

## Editorial changes applied throughout

- Replaced institution-specific titles and metadata with topic-based wording.
- Standardised notation and topic-based filenames.
- Added reading order, cross-links, format tables, and source-status labels.
- Preserved or recreated diagrams in TikZ where diagrams materially aid understanding.

## LLM assistance

A large language model was used during preparation of the repository. It assisted with reconstructed and companion material, explanatory drafts, editorial restructuring, examples, diagrams, navigation, consistency checks, and conversion between LaTeX and Markdown.

The source-status labels in this file describe whether earlier artifacts were locally recoverable; they do not imply that a document was prepared without LLM assistance. Readers should independently check mathematical and physical claims against authoritative sources.

## External-source caution

No third-party teaching handouts have been bundled. References made in earlier chats to external handouts are not evidence of redistribution permission and are intentionally absent from this repository.
