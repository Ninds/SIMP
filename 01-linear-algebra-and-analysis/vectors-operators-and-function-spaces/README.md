# Vectors, operators, and function spaces

These notes form the linear-algebra backbone of the collection. They begin with geometric vectors and dot products, then compare finite coordinate lists, square-summable sequences, and functions.

Later sections introduce projections, norms, operators, adjoints, eigenvectors and eigenfunctions, Fourier coordinates, the heat equation, and the infinite square well.
