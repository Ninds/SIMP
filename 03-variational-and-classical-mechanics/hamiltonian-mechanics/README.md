# Hamiltonian mechanics

These intuition-first notes build a gentle bridge from Lagrangian mechanics to phase space. They motivate conjugate momentum and the Legendre transform before deriving Hamilton's equations, then develop worked examples, conservation, phase portraits, and links to quantum mechanics.

## Available editions

- [Readable Markdown](hamiltonian-mechanics.md)
- [Typeset PDF](hamiltonian-mechanics.pdf)
- [LaTeX source](hamiltonian-mechanics.tex)

The PDF and LaTeX source are the recovered matching editions. The Markdown file is a repository-friendly reading edition generated from that source; diagrams and exact typesetting remain in the PDF and LaTeX editions.

Prerequisites: the core ideas in [Lagrangian mechanics](../lagrangian-mechanics/README.md). The Hamiltonian later reappears as an operator in the [Schrödinger bridge](../../04-quantum-mechanics/schrodinger-operator-bridge/README.md).
