# Euler–Lagrange illustrated problem workbook

This workbook contains fifteen progressive problems on oscillators, pendulums, polar motion, constraints, central forces, moving supports, rotating systems, velocity-dependent terms, and coupled oscillations.

The PDF gives each problem its own page with ruled working space. A separate solutions section provides complete worked answers.
