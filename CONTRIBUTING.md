# Contributing

Contributions should preserve the collection's teaching style:

- Begin with the question the mathematics answers.
- Define notation locally and avoid unexplained symbols.
- Show the algebraic steps that carry conceptual weight.
- Include a geometric, dimensional, or limiting-case check.
- Keep titles and metadata institution-neutral.
- State clearly whether a document is recovered, adapted, or newly written.

When changing a LaTeX source, rebuild the PDF and inspect every affected page for clipping, overlap, broken references, and unreadable diagrams. Update the matching Markdown edition when the mathematical content changes.
