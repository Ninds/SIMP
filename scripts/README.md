# Repository utilities

This folder contains maintenance tools rather than mathematics notes.

- `build_all.py` rebuilds or cleans every LaTeX document while preserving the topic-folder layout.
- `tex_to_markdown.py` regenerates the browser-friendly Markdown editions from the LaTeX sources. Diagrams remain in the PDF and LaTeX editions and are identified in Markdown by explanatory placeholders.

See [BUILDING.md](../BUILDING.md) for requirements and commands.
