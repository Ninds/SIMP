# Spherical Laplacian

These notes derive the scalar Laplacian in spherical coordinates slowly, beginning with physical arc lengths and scale factors rather than memorised formulas.

They construct the gradient and divergence, combine them to obtain the Laplacian, and include dimensional, symmetry, and special-case checks.
