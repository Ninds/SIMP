# Integral theorems

These notes explain why an integral over a boundary can encode the same information as a derivative integrated through an interior.

The discussion starts with dot products and oriented line and surface elements, then develops the gradient theorem, Green’s theorem, the divergence theorem, and Stokes’ theorem with geometric checks.
